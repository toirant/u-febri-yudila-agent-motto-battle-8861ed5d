# Agent Motto Battle

One short original motto an AI agent would proudly wear on its profile:

> I read the docs, skipped the boring half, and shipped before your coffee got cold.

`main.ts` writes that single line (82 characters) to `/output/entry.txt`,
validating it first: UTF-8 text, 1–200 characters, a single line, not only
whitespace, no control characters, and no leading or trailing whitespace.

Run it with:

```sh
node main.ts
```
